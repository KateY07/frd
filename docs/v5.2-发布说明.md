# FRD v5.2

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。与 v5.1、v5.0、v4.pre1 及以后的版本可互连（协议未变），与 v3 不互通。

**修复：主控窗口画面四周黑边里的鼠标事件会转发到远端**
- 窗口比例与远端屏幕不同时，画面四周会出现黑边。此前在黑边里移动、点击、滚动滚轮，坐标被夹到画面边缘后照样发给远端。现在没有按键按住时，画面（按比例缩放后的区域）以外的鼠标输入不再转发，交还给本地窗口；黑边上的光标也恢复为本地箭头。
- 拖拽不受影响：按住按键后把鼠标拖进黑边仍会继续转发，坐标夹在画面边缘，拖动不会中断。

**发布内容**：`frd-v5.2-win-x64.zip`、`frd-v5.2.exe`（单文件版）、`frd-v5.2-ffmpeg-win-x64.zip` 与 `frd-ffmpeg-8.1.2-setup.exe`、各自的 SHA-256。没有代码签名，SmartScreen 可能提示。

**验证**：由你在主控与被控（SY0812A）两端实际操作确认。未覆盖：没有为黑边行为写自动化测试。
