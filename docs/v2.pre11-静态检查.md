# FRD v2.pre11 静态检查

检查范围：关闭流程（`FfmpegUi.cs` 的 `Shutdown`、`FfmpegHostWindow.cs` 的 `Closing`）、新增 `FfmpegShutdown.cs`、被控端退出按钮、版本元数据和发布说明。

- `FRD.csproj` 的信息版本为 `v2.pre11`，与 Git 标签及输出目录一致。
- `ShutdownGuard.Bounded` 对单步清理加超时；超时后跳过依赖该步骤的同步 `Dispose`（避免 UI 线程在 `GetResult` 上死锁）。
- `ShutdownGuard.Arm` 为 10 秒进程级看门狗：先 `Environment.Exit`，2 秒后仍未退出则 `Process.Kill`。二次关闭（首次关闭 2 秒后）调用 `Kill`。
- 被控端窗口无任务栏、无主窗口句柄，`CloseMainWindow` 无效；新增的退出按钮是唯一的界面内关闭入口。
- 不改动传输、编码、输入协议、端口或安全桌面辅助服务。
- 验证为实机：挂起对端后关闭耗时见发布说明；强制退出路径未被实际触发，仅为代码审查。
