# FRD v1.pre11 静态检查与发布验证

- v1.pre10 的云端任务已成功完成检出、.NET 10 安装、固定 FFmpeg 下载及 SHA-256 校验、Release 构建、包版本与 SHA-256 复核，以及 Actions artifact 上传。
- v1.pre10 仅在最后的 GitHub CLI Release 创建步骤失败，未产生 GitHub Release；既有标签保留作为失败运行证据。
- v1.pre11 使用 GitHub 自动提供的短期 `GITHUB_TOKEN` 直接调用 Releases API，权限保持为 `contents: write`，不保存个人令牌。
- 官方 Actions 更新为 checkout v5、setup-dotnet v5 和 upload-artifact v5，消除上一轮 Node.js 20 弃用警告。
- 发布脚本仍验证 Git 标签与项目版本一致、ZIP 存在且 SHA-256 匹配，再上传 workflow artifact 和 GitHub Pre-release 资产。

GitHub runner 无真实桌面和目标 GPU，因此云端流程不代替真实屏幕、硬件编码器或双机交互回归。程序功能回归范围见 [v1.pre9 静态检查](v1.pre9-静态检查.md)。
