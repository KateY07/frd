# FRD v1.pre7

本版解决键鼠事件逐个等待业务 ACK 导致的输入积压：保持发送顺序，允许最多 64 个请求在途，回执独立接收。持续滚轮或键盘输入不再因每个事件等待一次往返而堆积。

关闭转发、取消、断线、错误回执及 5 秒 ACK 超时均有明确处理。关闭请求即使在写入前被取消，也关闭连接并进入被控端释放按键的流程；远端拒绝释放时保留拒绝结果和错误日志。

## 验证

- 原有输入回归 30 项通过；流水与关闭安全回归 32 项通过。
- 延迟回归 18 个场景通过，包含请求与 ACK 双向附加延迟。模拟回复实际延迟约 30.8 ms、持续 120 Hz 输入时，生成到模拟注入器的平均时间由串行基线约 2727 ms 降至约 0.27 ms。该值不包含真实网络传播、系统注入或视频回显。
- 受限网络实验 7 个场景完成完整性检查。它们使用真实 TCP 输入与 UDP 收发，视频为合成负载；TCP 传输 ACK 开销属于模型。通过仅表示输入顺序、UDP 检查及实验完成，**不表示拥塞视频已经可用**；其中一个超载优先调度场景没有完整视频帧。

## 交付范围

编码预设与码率仍由用户手动控制，本版不接入自动降码率或新的公网拥塞控制。本机 Demo 仍把滚轮和键盘送往专用测试文本窗口；真实网页定向输入只在独立实验中验证，尚未成为正式 Demo。现有主控布局保持原样。

本轮没有新增真实双机、同条件 RDP 对比或最终视频响应延迟验收。详细证据见 [静态检查与回归记录](v1.pre7-静态检查.md)，CLI 入门见 [使用](使用.md)。

交付包含自包含 Windows x64 程序、FFmpeg 依赖、可编辑 JSON、README 和说明文档；只推送 Git 版本标签，ZIP 与 SHA-256 保留本机。发布前主项目与单文件 Demo 均已编译通过，32 项流水可靠性短测重新通过；最终包校验值随安装包提供。
