# FRD v2.pre8 静态检查

检查范围：被控端窗口（新增 `FfmpegHostWindow.cs`）、共享毛玻璃样式、主控浮层间距、版本元数据和发布说明。

- `FRD.csproj` 的信息版本为 `v2.pre8`，与 Git 标签及输出目录一致。
- 本版仅改动界面层，不改动传输、编码、输入协议或安全桌面辅助服务；`HostWindow` 从 `FfmpegRemote.cs` 移至独立文件，`RemoteLaunch` 改为 partial。
- 被控端窗口沿用 `SetWindowDisplayAffinity(0x11)` 排除捕获，并把窗口句柄注册为控制器窗口，远程指针落在其上被拒绝；新增 `WS_EX_NOACTIVATE`，远程键盘事件不会落到该面板。
- 控制浮层回归（`--demo-regression`）通过。被控端窗口的动画、胶囊与自动展开为实机观察验证，没有自动化回归。
