# FRD v4.pre1 静态检查

检查范围：认证与会话密钥（`src/Net/Auth.cs`）、UDP 键鼠包格式（`src/Channels/Input.cs`）、握手与限速（`src/Remote/RemoteHost.cs`）、辅助服务安装（`tools/FrdWinTools/SecureService.cs`）、日志（`src/Support/CrashLog.cs`）、目录结构、打包清单。对应 `docs/审查-v3.pre4-静态审查与架构分析.md` 中的第 1、2、3、4、5、6 项。

- 版本：两个项目的信息版本均为 `v4.pre1`；协议版本 `RemoteAuth.Version = 3`，握手版本不一致时给出“需同时升级”的提示。
- 认证：口令只用于派生密钥，不出现在任何报文；比较一律 `CryptographicOperations.FixedTimeEquals`；每个连接使用新的 32 字节随机挑战。派生成本约 25 ms/连接，仅在建立连接时发生，不在视频或键鼠热路径上。
- 键鼠包：包长 56 → 72 字节（尾部 16 字节 HMAC-SHA256 截断），验证先于任何字段解析；本机回环路径使用固定的 `LocalKey`（无远端对等方）。
- 未做：画面、剪贴板、光标、控制消息的内容加密（需要对 UDP 报文做 AEAD，并处理 MTU、序号和重放），已在启动提示、README 与主页中明示“未加密”。UDP 注册与反馈报文仍只靠 TCP 下发的随机数识别，未签名。
- 辅助服务：`InstallBinary` 先以只允许读共享的方式打开源文件，计算 SHA-256 后复制并复核哈希，再原子替换；目录权限为 SYSTEM/Administrators 完全控制、Users 读与执行。该路径需要管理员权限，本次**没有实际运行**，只通过编译与代码审阅。
- 目录：`src/` 下 11 个子目录，根目录不再有 `.cs`；`FRD.csproj` 用 `src/**/*.cs`；辅助服务与测试工程中的链接路径已同步。
- 编译：主程序、辅助服务、Glasspane 均 0 错误 0 警告。
- 测试：`tests/Run-Tests.ps1` 中 `Core`、`Diagnostics` 通过；`Stats` 在本次的非交互会话中因 DXGI 桌面复制被拒绝而失败（环境原因，需在交互会话运行）。
