# FRD v5.5

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。与 v5.4、v5.3、v5.2、v5.1、v5.0、v4.pre1 及以后的版本可互连（协议未变），与 v3 不互通。

**新增：主控窗口标题栏参数 `--title`**
- `FRD.exe --connect 被控IP --port 5000 --token 口令 --title "我的远程桌面"`：用指定文字作为主控窗口的标题栏文字。仅主控端有效，给 `--host` 传 `--title` 会报参数错误；1–200 个字符，不能为空，不能含控制字符，含空格要加引号。不传时仍是原来的默认标题。

**新增：固定的 FRD 图标**
- 内置图标（深蓝圆角底、浅蓝显示器、白色鼠标指针，`assets/frd.ico`，16 到 256 多个尺寸）作为 `FRD.exe` 的应用图标嵌入，主控窗口的标题栏和任务栏也使用它。没有 `--icon` 参数，图标是固定的。

**发布内容**：`frd-v5.5-win-x64.zip`、`frd-v5.5.exe`（单文件版）、`frd-v5.5-ffmpeg-win-x64.zip` 与 `frd-ffmpeg-8.1.2-setup.exe`、`frd-service-v5.5-setup.exe`、各自的 SHA-256。没有代码签名，SmartScreen 可能提示。辅助服务本版无变化，已装的服务不必重装。

**验证**：在本机起了被控端和主控端，`--title "测试标题 XYZ"` 后窗口标题正是这段文字；向窗口查询图标，大小图标句柄均不为零；`FRD.exe` 本身可提取到图标；空标题和 `--host --title` 报错。**未覆盖**：16 像素标题栏下图标的清晰度只看了 256 像素的预览；没有为 `--title` 写自动化测试。
