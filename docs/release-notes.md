# FRD v4.pre1

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。**连接协议升级，主控端与被控端必须同时升级到 v4**（与 v3 不互通）。本版根据 v3.pre4 的静态审查修复了高、中危安全问题，并整理了代码结构。

安全
- **认证改为挑战-应答，口令不再上网**：被控端先发随机挑战，主控端用口令派生密钥（PBKDF2-SHA256，50,000 次）回答 HMAC 证明，被控端再回送证明（双向认证）；嗅探到的握手无法重放。
- **键鼠包签名**：UDP 键鼠包增加 16 字节 HMAC（密钥来自本次会话），无有效签名的包被丢弃，旁路攻击者无法再注入键鼠。
- **失败限速**：同一地址认证失败后指数退避（1、2、4…最长 60 秒），并限制同时进行的未认证握手（16 个）。
- **不加密内容（有意为之）**：FRD 只做认证和键鼠签名，不加密画面、剪贴板、光标与控制消息；它假定运行在已加密的底层链路（VPN、隧道、专网）上，画面路径因此没有额外的包大小或延迟开销。被控端启动提示、README 与主页已按此措辞说明。
- **辅助服务防本地提权**：安装时把 `frd-wintools.exe` 校验哈希后复制到 `%ProgramFiles%\FRD\`（SYSTEM 与管理员可写，普通用户只读），服务指向该副本，不再指向解压目录；升级时先停服务再覆盖。**升级后需要再点一次“安装辅助服务”**。
- **日志脱敏**：崩溃日志不再写入 `--token` 的值，启动时清理旧日志只保留最近 20 个，并抹掉保留下来的旧日志里的口令。

代码
- 源码按职责整理到 `src/` 的 `Capture`、`Codec`、`Net`、`Channels`、`Secure`、`Session`、`Remote`、`Config`、`Support`、`Regression`、`Ui` 目录；去掉 `Ffmpeg` 前缀；`FfmpegApp.cs` 与 `FfmpegRemote.cs` 按类型拆成多个文件。命名空间与行为不变。
- 已无法编译的 9 个测试工程和旧的单文件示例移到 `legacy/`；新增 `tests/Run-Tests.ps1` 运行仍可用的测试。
- 清除全部编译警告（含 Glasspane 子模块）。

验证：AOT 构建上的本机回环远程会话（正确口令通过；错误口令被拒绝并触发退避）、本机回归、`Core` 与 `Diagnostics` 测试通过。**未验证**：辅助服务的实际安装（需要 UAC，本机未执行）、键鼠包签名在真实键鼠转发下的端到端效果、SY0812A 跨机会话。
