# FRD v2.pre11

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 被控端新增“退出被控端”：窗口没有任务栏图标，此前没有任何关闭入口，只能用任务管理器结束。现在在“更多”中点击即可停止监听并退出（被控时会先断开）。
- 主控端与被控端关闭流程加入上限：各清理步骤最多等待 3–6 秒，整体 10 秒仍未结束则强制退出；关闭等待超过 2 秒后再次点击关闭，立即强制退出。网络卡住不再让窗口无法关闭。
- 协议、端口、输入通道与安全桌面辅助服务不变，主被控端无需同时升级。

已编译主工程并通过控制浮层回归。实测：被控端进程被挂起时主控端 1.2 秒内可关闭；主控端被挂起时被控端 0.2 秒内可关闭；“退出被控端”点击后立即退出。未能构造出真正卡死的清理步骤，强制退出路径（10 秒看门狗、二次关闭）没有被实际触发过。
