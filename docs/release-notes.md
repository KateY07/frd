# FRD v5.3

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。与 v5.2、v5.1、v5.0、v4.pre1 及以后的版本可互连（协议未变），与 v3 不互通。

**修复：被控端打开任务管理器（管理员窗口）后，键鼠都无法转发**
- 原因：任务管理器以管理员权限运行，Windows 会静默丢弃普通权限进程注入给它的输入；它有焦点时，连点桌面或别的普通窗口的注入也一起被丢弃，控制通道看起来“卡死”。
- 修复：被控端发送每个事件前，读取焦点窗口和指针下窗口所属进程的完整性级别；只要焦点窗口是管理员或 SYSTEM 窗口，或指针下是这样的窗口，就把该事件交给已安装的 SYSTEM 辅助服务，在用户桌面上以 SYSTEM 身份注入。焦点回到普通窗口后自动切回原路径；切换时先释放按住的键和按钮。
- 新通道只监听 `127.0.0.1:59875`，沿用现有的本机密钥与 HMAC 认证。**需要重新安装一次辅助服务**（见下）才有这个通道；没装辅助服务时行为与 v5.2 相同。
- 取舍：这意味着已连接并获得输入权限的主控端可以操作被控机上的管理员窗口，与它能操作 UAC 和锁屏界面是同一级别的授权，仍然只在被控端装了辅助服务时才有。

**修复：辅助服务重装/升级失败**
- 已装过辅助服务时再次安装，会因为先写日志冲掉了错误码，把“服务已存在”误判为失败。现在先读错误码再写日志，失败信息里带上错误码。

**新增：辅助服务的独立安装包 `frd-service-v5.3-setup.exe`**（OneSetup）
- 基础包和单文件版里不再放裸的 `frd-wintools.exe`，改放这个安装包（它内置 `frd-wintools.exe`）；被控端界面的“安装被控服务”按钮现在启动它，不再直接提权运行 `frd-wintools.exe`。
- 双击后窗口里选择 **1 安装（覆盖）** 或 **2 卸载**，显示当前是否已安装；选择后弹出 UAC，由你亲自确认。完成后检查服务是否在运行、安装的文件是否与包内一致；卸载则检查服务和文件夹是否清除。
- 服务装在 `%ProgramFiles%\FRD`，只放服务用的 `frd-wintools.exe`。被控端 FRD 正在运行时会占用 `%ProgramData%\FRD\SecureDesktopProbe\frames.map`，卸载会提示它将在下次重启时删除（先关闭 FRD 可彻底清理）。
- 命令行：`frd-wintools.exe --uninstall-secure-helper`（管理员）可直接卸载；无人值守时设环境变量 `FRD_SERVICE_ACTION=install|uninstall` 运行安装包。

**升级辅助服务**：运行 `frd-service-v5.3-setup.exe` 选 1，或在被控端界面点“安装被控服务”。

**修复：重装辅助服务后键鼠全部无法转发**
- 重装时的 UAC 提示在安全桌面上弹出，辅助进程在“安全桌面已激活”的状态下被停止，共享文件 `frames.map` 里留下过期的“安全桌面激活”标志；新的辅助进程从普通桌面启动，只在“离开安全桌面”时才清除它，于是被控端一直认为当前是安全桌面，把所有键鼠交给安全桌面通道，日志里是 `Secure desktop input worker is unavailable`。现在辅助进程每次启动的第一轮检查就清除该标志。从旧版升级后需要用新安装包再装一次服务。

**被控端的“安装/修复安全桌面辅助服务”按钮始终可点**
- 服务正在运行时按钮也保留，标签为“修复/重新安装安全桌面辅助服务”，点击启动服务安装包，并直接指定“安装”动作（环境变量 `FRD_SERVICE_ACTION=install`），安装包不再多问一次，只弹出 UAC 由你确认。直接双击安装包仍会询问 1 安装（覆盖）/ 2 卸载。取消 UAC 后面板按新状态刷新，不再报“安装失败”。

**主控端窗口允许被截屏和录屏**
- 远程主控窗口不再设置“排除出屏幕捕获”，PrtSc、截图工具、游戏栏等可以截到它、录到它。只有同一台机器上的本机演示模式仍然排除（否则会拍到自己）；被控端的提示窗口仍然排除，避免被拍进发给主控的画面。

**默认关闭“诊断包”和“诊断信息”**
- 连接后不再自动开启独立诊断 UDP 包，也不再默认在画面左下角显示“诊断信息”。两者都可以在“更多”里手动打开；诊断包关闭时，本机分层计时照常，跨机延迟不可测（面板会提示）。这样默认不产生额外的诊断流量。

**发布内容**：`frd-v5.3-win-x64.zip`、`frd-v5.3.exe`（单文件版）、`frd-v5.3-ffmpeg-win-x64.zip` 与 `frd-ffmpeg-8.1.2-setup.exe`、`frd-service-v5.3-setup.exe`、各自的 SHA-256。没有代码签名，SmartScreen 可能提示。

**验证**：在 SY0812A 上用安装包实测了全新安装、覆盖安装和卸载（服务状态、文件夹、残留文件均已核对，UAC 由你确认）；任务管理器场景的最后一版修复（焦点在管理员窗口时所有事件走辅助服务）尚待你确认。未覆盖：没有自动化测试；安装包窗口里 1/2 两个按钮的点击没有人工点过（实测走的是环境变量指定动作的路径）。
