# FRD v5.4

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。与 v5.3、v5.2、v5.1、v5.0、v4.pre1 及以后的版本可互连（协议未变），与 v3 不互通。

**新增：被控端“截屏”标注工具**
- 被控端悬浮面板的图标行里新增相机图标“截屏”，始终可见（不需要有人在控制）。点击后抓取被控机主屏，弹出普通窗口“FRD 截屏标注”显示这张截图；FRD 自己的提示窗口本来就排除在屏幕捕获之外，不会拍进去。
- 在图片上标注，而不是在真实屏幕上画：工具栏有 4 种颜色、涂鸦、矩形、文字、粗、撤销、清除，与主控端的标注工具一致。标注烧进图片，不影响被控机上的任何操作，也不会发给主控端。
- 完成后“保存”为 PNG（图片\FRD 文件夹）、“复制”到剪贴板，或“关闭”放弃；快捷键 Ctrl+S / Ctrl+C / Ctrl+Z。
- 取舍：这版没有“把标注后的图片发送给主控端”，需要时可再加。

**升级辅助服务**：本版辅助服务无变化；已装 v5.3 的服务不必重装。

**发布内容**：`frd-v5.4-win-x64.zip`、`frd-v5.4.exe`（单文件版）、`frd-v5.4-ffmpeg-win-x64.zip` 与 `frd-ffmpeg-8.1.2-setup.exe`、`frd-service-v5.4-setup.exe`、各自的 SHA-256。没有代码签名，SmartScreen 可能提示。

**验证**：标注烧进图片的导出（笔画、矩形、文字落在对应位置、背景不变）和 PNG 写出，用合成图做了无界面测试，通过（`--shot-regression`）；UI 布局回归 86 个场景 0 个问题。**未覆盖**：截屏窗口里的实际点击交互（画几笔、保存、复制、缩放）和相机按钮在 SY0812A 被控端上的实机操作，需要你确认；没有为新窗口写自动化的界面测试。
