# FRD v2.pre7

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 主控端与被控端界面重做为深色毛玻璃（Acrylic）悬浮面板：状态点与主机名、键鼠、剪贴板、全屏、更多、断开，最右侧 `»` 收起。可拖动；收起为带连接状态点的毛玻璃悬浮球，收起/展开有过渡动画，空闲 10 秒自动收起。
- 编码预设、码率上限、帧率、诊断包与诊断水印移入“更多”；诊断水印默认显示，可随时隐藏。
- 被控端提示窗口改为同风格毛玻璃卡片，显示监听地址与连接状态，提供键鼠、剪贴板权限开关和断开；未运行安全桌面辅助服务时显示安装入口。
- 外部端口、会话协议、输入通道和安全桌面辅助服务均未改动，主被控端无需同时升级。

已编译主工程并通过控制浮层回归；毛玻璃的实际观感依赖 Windows 10/11 系统亚克力支持，不支持时退化为半透明。
