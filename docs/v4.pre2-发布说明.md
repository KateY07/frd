# FRD v4.pre2

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时。与 v4.pre1 可互连（新增的标注通道在旧被控端上自动降级为只在主控端本地显示）；与 v3 不互通。

**重要修复**
- **辅助服务安装崩溃**：v4.pre1 在创建服务时崩溃（RPCRT4 访问冲突，安装失败）。原因是 `CreateService` 的 `tag` 参数被声明成 32 位，API 要的是指针，NativeAOT 下高位是垃圾。已修复；安装过程写入 `%ProgramData%\FRD\SecureDesktopProbe\install-trace.txt`，崩溃时能看到最后一步。**v4.pre1 用户请升级。**
- **被控端鼠标闪烁**：被控端提示卡片每次重绘都用带 `CAPTUREBLT` 的 BitBlt 抓取屏幕做毛玻璃，会让鼠标指针闪烁。改为普通 `SRCCOPY`，并在卡片与窗口不动时最多每 0.75 秒抓一次。
- **主控悬浮面板拖动**：展开时拖动，控件原先留在原地；现在内容随面板一起移动（Glasspane 库已同步修复）。
- **面板重叠**：控制端顶栏的延迟文字压在按钮上、被控端状态文字压到按钮下；现在按钮空间不足时“键鼠/剪贴板”只显示图标。新增无窗口的布局回归 `FRD.exe --ui-layout-regression`，覆盖 40 种尺寸与状态，均无重叠。

**新功能**
- **本地键鼠优先**：被控端检测到实体键盘/鼠标正在使用时，丢弃远程键鼠事件（释放类事件放行，避免按键卡住），主控端显示“对方正在操作，请等待”。只读取“是否注入”标志和时间，不读取按键内容。
- **传输文件显示进度**：主控端画面底部浮条、被控端卡片内一行带进度条，显示方向、第几个文件、文件名、百分比和已传/总大小。
- **显示远程光标（可选）**：更多面板里的“远程光标”开关，在画面上叠加被控端鼠标指针的位置和形状，不开键鼠转发也能看到。默认关闭。
- **共享标注（画板）**：主控端可画涂鸦、矩形、文字（4 种颜色、粗细、撤销、清除，Esc 退出，Ctrl+Z 撤销），被控端屏幕同步显示，被控端覆盖层不拦截点击、排除在屏幕捕获之外；被控端卡片上有“标注”开关可随时禁止。标注走独立的 TCP 连接，低优先级、批量合并、被控端限速，不占用视频路径、不增加延迟。
- **帧率**：默认 25 FPS，可选 10/20/25/30，移除 60 FPS（配置校验、控制命令同步更新）。

**其他**
- 主页 Download 按钮只跳转 GitHub Releases 页面，由用户自行选择版本。
- 测试：新增 `tests/Run-Tests.ps1` 中的 UiLayout 项。

验证：AOT 构建上本机回环远程会话通过（25 FPS 编码）、布局回归 0 问题；在 SY0812A 上验证了辅助服务安装（服务运行于 `%ProgramFiles%\FRD\`）、共享标注（覆盖层可见、点击穿透、清除后隐藏）并由使用者目视确认了传输进度、远程光标、画板与面板。**未验证**：键鼠签名在真实键鼠转发下的端到端、实体键鼠让位（仅验证合成输入不会误触发，使用者目视确认可用）。
