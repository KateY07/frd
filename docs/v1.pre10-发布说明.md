# FRD v1.pre10

Windows x64、依赖 .NET 10 x64 Runtime 的便携预发行版。程序功能与 v1.pre9 相同：包含原始分辨率捕获、FFmpeg 编解码、UDP 视频、远程输入、双向剪贴板和同一会话网络暂停恢复修复。

本版新增可复现的 GitHub Actions 发布流程。推送与项目版本一致的 `v*` 标签后，Windows runner 下载并校验固定版本的 FFmpeg 运行库，执行 `Publish.ps1`，核对 ZIP 的版本和 SHA-256，上传 Actions artifact，并创建带便携 ZIP 与 `SHA256SUMS.txt` 的 GitHub Pre-release。工作流使用 GitHub 自动提供的短期令牌，不需要在仓库保存个人令牌。

便携包不自包含 .NET，也不启用 Native AOT。主控与被控机器需预先安装 .NET 10 x64 Runtime。SYSTEM 安全桌面辅助进程仍未纳入便携包；码率仍由用户手动控制，没有自动拥塞降码率。

功能验证和边界沿用 [v1.pre9 静态检查](v1.pre9-静态检查.md)，CLI 使用见 [使用与配置](使用.md)。
