# FRD v1.pre13 静态检查与回归

- 主工程及由生产源码生成的单文件 Avalonia Demo 已以 Release 配置构建，结果为零警告、零错误。
- 远程控制握手已删除 `VideoPort`、`DiagnosticPort` 和 `SenderPort`；源码与 CLI 不再要求额外主被控业务端口。
- 单端口本机转发回归覆盖视频、反馈、诊断和输入，以及 100 ms、500 ms、1 s、3 s、5 s、10 s 的同会话停顿；恢复后继续使用原 TCP 连接和 UDP 映射。
- 正式单 socket 输入回归覆盖鼠标移动、按钮、滚轮、键盘、全量释放、错误会话、旧序号和禁用状态。输入 UDP 不等待 ACK，也不重复发送。
- 鉴权回归确认正确口令建立会话，错误口令和错误会话被拒绝，带会话证明的 UDP 注册发送至固定 `--port` 并收到确认。
- IPv6 双栈监听允许 IPv4 主控使用同一固定端口；诊断发送接受双栈 socket 的 IPv4 回程端点。

本机转发回归不等同于真实 ArdUi/ardJ 公网验收。真实双机预览已用于定位并修复双栈 socket 向 IPv4 回程端点发送诊断时的地址族校验错误。
