# FRD v5.4 静态检查

检查范围：`src/Support/ScreenShot.cs`（`ScreenGrab`、`PngWriter`、`ImageClipboard`）、`src/Ui/UiShotWindow.cs`（`UiShotPanel`、`UiShotWindow`、`ShotComposer`）、`src/Ui/UiHostWindow.cs` 的相机按钮。

- 版本：两个项目为 `5.4.0` / `v5.4`；协议、端口、预设、辅助服务不变。
- 抓屏：GDI `BitBlt(SRCCOPY)` 抓主屏到 `CreateDIBSection`，不带 `CAPTUREBLT`，设置了“排除出屏幕捕获”的 FRD 窗口不会出现在截图里；句柄与 DC 在 `finally` 里释放。所有新增 `DllImport` 的句柄、指针宽度参数为 `nint`/`nuint`。
- 标注烧录：`ShotComposer` 用 Direct2D 在离屏位图上画原图和 `AnnotationBoard`，再 `CopyFromBitmap` + `Map` 读回，线宽和字号按图片宽度的比例换算，与屏幕上显示一致。
- 导出：PNG 自写（zlib + CRC32），先写 `.part` 再改名；剪贴板用 `CF_DIB`，成功后内存归剪贴板，失败时释放。
- 范围：不新增网络通道，不向主控端发送任何内容；窗口是普通顶层窗口，关闭即销毁。
- 未覆盖：截屏窗口的人工点击；多显示器时只抓主屏；高 DPI 缩放下窗口内的标注定位只做了与主控端相同的换算，没有单独验证。
