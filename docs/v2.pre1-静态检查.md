# FRD v2.pre1 静态检查与回归

## 修复边界

- 保持单个外部端口、最多四条业务 TCP 连接和 1172 字节 UDP 上限。
- 公共收包仅承担校验、分流及反馈统计；阻塞式输入在独立线程执行，队列有界，移动合并不跨越按钮/键盘事件。
- 不放宽来源校验，不把 TCP EOF 当作可恢复停顿；重复注册仅接受当前已关联端点，不产生输入/视频使用不同端点的状态。
- 诊断故障降级；收包或输入执行的不可恢复故障立即通知会话所有者。

## 针对性回归

以下项目本轮均已通过。主工程和同步生成的单文件 Avalonia Demo 均为 Release 构建，零警告、零错误；测试变化画面窗口已关闭。

- `tests/PathSwitchResilience --udp-resilience-only`：未鉴权的 4096/65000 字节 UDP 报文、输入阻塞期间的视频反馈、移动合并与按钮/键盘顺序、128 项队列饱和释放、诊断回调故障隔离、不可恢复 socket 故障通知、五次注册超时提示、主动取消。
- `tests/PathSwitchResilience --same-session-only`：真实 DDA 捕获小型变化窗口、FFmpeg 编解码，经不同 P/Q 端口的本机转发器，在同一会话注入 100/500/1000/3000/5000/10000 ms 停顿；恢复后必须新增至少三帧解码画面，并确认被控端输入注入成功。另测丢包/乱序、视频 UDP 停顿、诊断/反馈独立恢复、输入 TCP 停顿及显式关闭对照组。
- `tests/PathSwitchResilience --auxiliary-path-only`：生产剪贴板与鼠标形状协议通过原 TCP 连接恢复；双向文本、文件 SHA-256、嵌套/空目录及光标形状/热点验证。使用独立协议夹具和内存剪贴板，不改动系统剪贴板。
- 既有 `MouseFollowDual --udp-loopback`：移动、按钮、滚轮、键盘、全量释放以及错误会话、旧序号、禁用状态拒绝均通过。
- 既有 Diagnostics 回归 19 项通过，包含 IPv4/IPv6、反馈、诊断及视频包格式；Remote `--auth-only` 的 CLI 版本、口令、会话和固定 UDP 注册回归通过。

本机日志：`results/v2.pre1-udp-resilience.log`、`results/v2.pre1-path-recovery.log`、`results/v2.pre1-input.log`、`results/v2.pre1-diagnostics.log`、`results/v2.pre1-auth.json`、`results/v2.pre1-demo-build.log`。日志为本机构建产物，不进入发布包；本文件随发布包提供。

这些验证不代表真实 ArdUi/ARD 公网验收；无头解码恢复不等同于显示器物理呈现。安全桌面 ACK 阻塞通过受控阻塞注入器验证线程隔离，没有冒充本轮已完成真实 UAC/锁屏双机测试。
