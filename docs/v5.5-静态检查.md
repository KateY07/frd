# FRD v5.5 静态检查

检查范围：`src/Remote/RemoteLaunch.cs`（`--title` 解析）、`src/Ui/UiApp.cs`、`src/Ui/UiControllerWindow.cs`（标题与图标）、`src/Ui/AppIcon.cs`、`FRD.csproj` 的 `ApplicationIcon`、`assets/frd.ico`。

- 版本：两个项目为 `5.5.0` / `v5.5`；协议、端口、预设、辅助服务不变。
- 参数：`--title` 加入 `Parse` 的允许列表；仅 `--connect` 接受，`--host` 与之一起出现按参数错误处理；校验非空、不超过 200 个字符、不含控制字符。默认标题逻辑不变，只有显式传入时才覆盖。帮助文本与英文翻译表同步更新（`Usage` 整串是翻译键，两处一并改）。
- 图标：`ApplicationIcon` 把 `assets/frd.ico` 嵌入 exe；`AppIcon.Apply` 用 `ExtractIconEx` 取出大小图标并 `WM_SETICON` 到主控窗口，失败只写日志。新增 `DllImport` 的句柄参数为 `nint`；图标句柄随进程结束回收。
- 未覆盖：自动化测试；被控端提示窗口与截屏窗口不使用该图标。
