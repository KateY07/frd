# v1.pre4 静态检查与验证记录

日期：2026-09-18。本版范围为 Avalonia Simple 主题、紧凑控制栏、全屏、可拖动悬浮球及独立水印显隐。本文记录发布前证据；完整回归按用户要求在发布后进行，不将历史 pre3 结果当作本版通过证据。

## 变更范围

- 主工程与单文件 Demo 项目使用 `Avalonia.Themes.Simple 12.1.1`，版本为 `1.0.0-pre4` / `v1.pre4`；被控窗口同步切换 Simple 主题。
- 码率仅通过滑条调整，数值标签显示 Mbps；滑条上限继续来自 JSON 的 `maximumBitrateMbps`。
- Ctrl+Alt 退出键鼠转发，Ctrl+Alt+F11 切换全屏；启用转发时，单独按 Esc 或 F11 保留远端输入含义。
- 展开控制栏可从空白区域拖动，交互控件不触发面板拖动；收起后显示 50 像素半透明悬浮球，区分拖动与单击。两种状态均限制在视口内，窗口尺寸变化时保留位置并按可见范围调整。
- 水印显隐独立于诊断开关；隐藏时不改变诊断包生成，仍保留原生鼠标穿透与不激活行为。
- 保留控制台入口、阻塞退出、必填监听地址/端口/口令及 IPv4/IPv6 接口。生成的 `demo/FrdDemo.cs` 由同步脚本维护。

## 发布前证据

- 主工程构建及自包含打包成功；单文件 Demo 已同步，曾完成独立构建，最后快捷键与指针事件保护调整后仍需再次独立编译。
- 本机 UI 短测 `results/release-v1.pre4/ui.json`：Passed=true，接收 241 帧、GPU 确认 239 帧、Errors 为空；覆盖四种窗口尺寸、控制栏与悬浮球边界、位置保留、全屏恢复、水印显隐及穿透。该短测不注入远端键鼠，最终拖动体验由用户人工确认。
- 用户确认“UI没问题”。当前版本已通过 ZIP 运维部署到 RTX 5070 Ti 对机，并建立 NVIDIA 硬编 → 本机软件解码连接；连接演示不替代双机完整回归。

## 发布后回归范围

- CLI 参数失败、口令认证、正常存活、窗口关闭退出与 IPv4/IPv6；传输、诊断及一秒统计。
- 手动码率、预设与比例切换，真实屏幕编码/传输/显示；双向文本、文件、目录剪贴板及 Windows 复制交接。
- 同步后的单文件 Demo 独立构建与实际发布产物检查。自动键鼠回归继续暂停。
