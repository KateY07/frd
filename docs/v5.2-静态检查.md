# FRD v5.2 静态检查

检查范围：`src/Channels/Input.cs` 的 `NativeInputSource`（鼠标转发判断、光标设置）。

- 版本：两个项目为 `5.2.0` / `v5.2`，与标签一致；协议、端口、预设不变。
- 新增 `IsLocalPoint`：面板命中或点在 `VideoArea` 之外都视为本地。没有按键按住时，本地点不转发（移动、按下、滚轮），并让本地窗口处理；`WM_SETCURSOR` 同样使用该判断。
- 按住按键期间保持转发，`InputCoordinates.Normalize` 仍把坐标夹到 0..1，拖出画面不会丢失按键释放。
- `VideoArea` 来自 `UiVideoView.VideoAreaPixels`（按比例缩放后的矩形）；未设置时退回整个客户区，行为与以前一致。
- 未覆盖：自动化测试。
