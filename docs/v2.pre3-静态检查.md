# v2.pre3 检查与验证范围

本版先发布，完整可观测性审计尚未完成。

已确认：默认配置与 C# 缺省值统一为 h264、2500 Kbps、不自动切换预设；示例与单文件 Demo 同步。预设使用 CRF 20 加 VBV 码率上限，允许瞬时发送突发，不额外做链路限速。

已验证：定向统计锁阻塞前后对照、不同背景视频码率下的生产单端口 UDP 输入、异常大包及诊断故障隔离、输入生命周期回归、双机真实鼠标确认标记返回并绘制。具体数值和局限见 [测试报告](单端口输入延迟回归.md)。

不能据此宣称整体鼠标卡顿已彻底解决：双机正常局域网短测结果相近且波动，未覆盖实际 ArdUi/FRP 受限公网链路。完整闭环测量不包含物理鼠标采样、正式主控输入采集队列或显示器扫描输出。

待审计：捕获前等待是否漏计；诊断缺失、迟到、异常样本对平均值的影响；静止与断流下延迟/FPS显示；跨机时钟误差；带宽统计范围与采样窗口；生产界面是否明确区分视频阶段时间和完整交互延迟。
