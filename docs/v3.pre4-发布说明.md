# FRD v3.pre4

Windows x64，Native AOT 单文件 `FRD.exe`，无需安装 .NET 运行时；代码、协议、端口与 v3.pre3 完全一致，可互连。

- 新增 MIT 许可证（`LICENSE`），两个发布包都附带许可证与第三方声明。基础包含 `LICENSE`、`THIRD-PARTY-NOTICES.md` 和 .NET 的第三方声明（`licenses/dotnet-ThirdPartyNotices.txt`）；FFmpeg 扩展包含 FFmpeg 的 GPL-3.0 许可证、源码获取说明（`ffmpeg/SOURCE-OFFER.txt`）以及上述声明。
- 第三方声明重写：列出每个包含哪些第三方代码、各自的版权行和许可证；说明基础包不含 FFmpeg，只有同时分发 FFmpeg 扩展包时才需要按 GPL-3.0 提供其对应源码。
- 主页页脚增加 MIT 许可证链接。
