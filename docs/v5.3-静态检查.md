# FRD v5.3 静态检查

检查范围：`src/Channels/InputInjector.cs`（`TargetIsElevated`、`IntegrityLevel`）、`src/Secure/SecureInput.cs`（`SecureDesktopInputRouter` 的管理员通道）、`tools/FrdWinTools/SecureService.cs`（用户桌面输入线程、安装错误码、卸载）、服务安装包（`tools/ServiceSetup`）、`Publish.ps1`。

- 版本：两个项目为 `5.3.0` / `v5.3`；协议、端口、预设不变；新增本机回环端口 `59875`（仅 127.0.0.1，需密钥）。
- 管理员判断：读目标进程令牌的 `TokenIntegrityLevel`（RID）与本进程比较；读不出视为更高。键盘看焦点窗口；鼠标看焦点窗口与指针下窗口。所有新增 `DllImport` 的指针/句柄参数均为 `nint`。
- 路由：`SecureDesktopInputRouter` 保留 `previousElevated`，两条路线切换时先在旧路线上 `ReleaseAll`；`ReleaseAll` 同时通知普通、安全桌面和管理员通道。管理员通道客户端只在辅助服务密钥存在时创建。
- 辅助服务：新增线程以 `SetThreadDesktop(Default)` 在用户桌面上用 SYSTEM 身份注入，复用 `SecureDesktopInputWorker`（密钥/HMAC、序号、会话切换释放）。
- 安装：`CreateService` 的错误码在 `Trace()` 之前读取。卸载先停服务、`DeleteService`，再删程序目录与数据目录，删不掉的会列出并返回 2。
- 入口：`SecureDesktopService.InstallViaUacAsync` 先找 `FRD.exe` 同目录的 `frd-service-*-setup.exe` 并启动、等待退出，再用服务状态判断是否成功；找不到安装包时（开发构建）退回直接提权运行同目录的 `frd-wintools.exe`。`Publish.ps1` 把安装包放进基础包和单文件版，并从包里移除裸的 `frd-wintools.exe`。
- 安装包：`install.ps1` 先校验包内 `frd-wintools.exe` 的 SHA-256，再用 `Start-Process -Verb RunAs` 提权运行 `--install-secure-helper <当前用户SID>` 或 `--uninstall-secure-helper`，不自己提权、不绕过 UAC；结束后核对服务状态和安装文件的哈希。被占用的文件通过 `MoveFileEx` 登记为重启时删除。
- 未覆盖：自动化测试；安装包窗口里按钮的人工点击；多用户同时登录时辅助服务的行为。
