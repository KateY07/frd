# FRD v5.3 静态检查

检查范围：`src/Channels/InputInjector.cs`（`TargetIsElevated`、`IntegrityLevel`）、`src/Secure/SecureInput.cs`（`SecureDesktopInputRouter` 的管理员通道）、`tools/FrdWinTools/SecureService.cs`（用户桌面输入线程、安装错误码、卸载）、两个 bat 脚本、`Publish.ps1`。

- 版本：两个项目为 `5.3.0` / `v5.3`；协议、端口、预设不变；新增本机回环端口 `59875`（仅 127.0.0.1，需密钥）。
- 管理员判断：读目标进程令牌的 `TokenIntegrityLevel`（RID）与本进程比较；读不出视为更高。键盘看焦点窗口；鼠标看焦点窗口与指针下窗口。所有新增 `DllImport` 的指针/句柄参数均为 `nint`。
- 路由：`SecureDesktopInputRouter` 保留 `previousElevated`，两条路线切换时先在旧路线上 `ReleaseAll`；`ReleaseAll` 同时通知普通、安全桌面和管理员通道。管理员通道客户端只在辅助服务密钥存在时创建。
- 辅助服务：新增线程以 `SetThreadDesktop(Default)` 在用户桌面上用 SYSTEM 身份注入，复用 `SecureDesktopInputWorker`（密钥/HMAC、序号、会话切换释放）。
- 安装：`CreateService` 的错误码在 `Trace()` 之前读取。卸载先停服务、`DeleteService`，再删程序目录与数据目录，删不掉的会列出并返回 2。
- 脚本：bat 为纯 ASCII；未提权时用 PowerShell `RunAs` 重启自身；卸载脚本从 `%TEMP%` 的副本运行。
- 未覆盖：卸载脚本未实际运行；自动化测试；多用户同时登录时辅助服务的行为。
