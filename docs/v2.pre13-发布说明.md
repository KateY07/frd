# FRD v2.pre13

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 安全桌面辅助服务安装加固：提权安装进程按“点击安装的交互用户”的 SID 授权密钥与共享帧文件，而不是提权账户自己的 SID（标准用户用管理员凭据提权时，后者会让被控端读不到密钥）。
- 被控端读取辅助服务密钥失败（无权限、被占用、长度异常）时，只关闭安全桌面功能并写日志，不再让被控端出错退出。
- 安装失败时，提权安装进程把原因写入 `%ProgramData%\FRD\SecureDesktopProbe\install-error.txt`，被控端的失败提示会带上首行原因。
- 新增崩溃日志：未处理异常写入 `%LOCALAPPDATA%\FRD\crash-<pid>.log`；被控端界面线程的未处理异常记录后继续运行。安装流程的每一步（请求、提权启动、安装进程退出码、服务状态、刷新界面）写入会话日志 `%LOCALAPPDATA%\FRD\session-<pid>.log`。
- 协议、端口、输入通道不变，主被控端无需同时升级。

说明：SY0812A 上“点击安装被控服务时整个进程闪退”在开发机上没能复现，本版是针对可能原因的加固与诊断，不保证已解决。若仍闪退，请提供该机 `%LOCALAPPDATA%\FRD\` 下最新的 `session-*.log`、`crash-*.log`，以及事件查看器“Windows 日志 → 应用程序”中 FRD.exe 的错误条目。
