# FRD v1.pre12 静态检查与发布验证

- 主工程及由生产源码生成的单文件 Avalonia Demo 均以 Release 配置编译通过，零警告、零错误。
- UDP 输入回环验证覆盖鼠标移动、按钮、滚轮、键盘、全量释放、会话伪造、旧序号和禁用状态。仅合法、最新且启用的输入被注入。
- 同一会话网络停顿回归覆盖 100 ms、500 ms、1 s、3 s、5 s、10 s 的 TCP 暂停，以及 UDP 丢包、乱序、视频/反馈/诊断单通道暂停。会话不被短暂停顿终止。
- 输入辅助 TCP 暂停期间，固定 UDP `--port` 的输入数据报仍经本机转发器到达被控端；显式关闭输入 TCP 仍会释放已按住的状态。
- 既有输入生命周期夹具 36 项通过，覆盖禁用、取消、断线、确认顺序、窗口背压和释放路径；它保留 TCP 回退模式的兼容性验证。

本轮未将真实双机公网、FRP、实际防火墙或全局系统键鼠注入宣称为自动化验收。UDP 输入不重传，因此单个按下/释放包可能丢失；会话关闭和禁用的 TCP 释放路径用于清理残留状态，不等同于 UDP 可靠传输。
