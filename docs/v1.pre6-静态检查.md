被控端为另一台 RTX 5070 Ti Windows 电脑，源桌面 2560×1440；主控为本机 Windows，桌面 2880×1800。视频通过两台机器的实际网络和 UDP 传输。用户已手工放行对机 pre5 程序的防火墙；自动化未修改防火墙。

### 覆盖内容

- NVIDIA H.264 / AV1 / HEVC 编码到本机软件解码；H.264 软件预设切换，0.5–5 Mbps 控制与两次连接；禁用的 AV2 不冒充支持。
- 可视滑条按 0.5、5、10、20、5 Mbps 调整，被控端确认值一致；本项验证控制链路，不据此宣称高画面需求下长期码率的独立测量。
- 1×、0.75×、0.5× 真实解码尺寸分别为 2560×1440、1920×1080、1280×720；窗口尺寸变化时水印保持穿透且位于画面内部。
- 本机→对机、对机→本机：多行 Unicode 文本、文件、重复文件名、嵌套与空目录；内容校验、接收端独立暂存路径，以及 Windows Shell 复制/替换/目录合并后重新读取。
- 测试前后的双方剪贴板备份恢复；同步关闭后才恢复，避免备份内容反向转发；测试窗口清理。

## 首次尝试与重测

第一次运行在覆盖本机剪贴板前安全停止：现有 `EnterpriseDataProtectionId` 格式无法读取，测试工具不能完整备份。没有绕过该保护或丢弃未知格式。用户复制可丢弃的普通文本后，从新目录重新运行完整双机交互回归并通过；旧失败记录保留在 `interaction/`，成功记录位于 `interaction-02/`。

## 继承及限制

继承 pre5 已修复的修饰键提前释放、监听取消竞态和状态文案问题，以及 pre4 人工确认的 Simple UI。已有本机定向回归覆盖输入消息 30 项、认证/退出 38 项、双栈 10 项；这些历史结果仍单独归属 pre5。

自动键鼠注入继续暂停；这次没有发送真实鼠标点击或键盘按键，也不宣称物理屏幕延迟测量。文件复制引擎在测试文件上自动确认替换/合并，不等同于自动点击用户实际文件对话框。
