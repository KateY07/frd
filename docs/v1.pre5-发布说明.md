# FRD v1.pre5

继承 v1.pre4 已确认的 Simple 界面；本版处理发布后静态审查发现的问题。保留 v1.pre4 标签，只新增 v1.pre5 标签；便携包及 README 保留本机，不上传 GitHub Releases。

- 正常松开鼠标后保留仍按住的 Ctrl、Shift 等远端按键，避免连续多选或后续拖动丢失修饰键。异常丢失鼠标捕获、失去焦点、退出转发及断开仍释放按键。
- 被控监听停止与异步接受连接之间的竞态按正常取消处理，避免正常关闭被误报为致命错误；其他异常继续输出并失败退出。
- 连接成功后控制栏立即显示已连接及编码参数；诊断包文案明确滑条只限制编码码率。
- 输入回归同步至 Ctrl+Alt / Ctrl+Alt+F11，验证 Esc、F11 单独透传、快捷键重复保护和修饰键释放。测试仅使用隐藏自有窗口消息及模拟注入器，不注入真实键鼠。

CLI、口令、监听范围、UDP 协议、编码配置及用户确认的 UI 形态不变。详细检查与验证边界见 [静态检查](v1.pre5-静态检查.md)，使用方法见 [使用](使用.md)。
