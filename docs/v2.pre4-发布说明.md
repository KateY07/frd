# FRD v2.pre4

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 安全桌面辅助服务改为复用同一个 `FRD.exe`：被控端未检测到运行中的 `FRDSecureCaptureProbe` 时显示安装按钮；点击后请求 UAC，并以 `FRD.exe --secure-service` 注册、启动 LocalSystem 服务。
- 服务在活动会话中以 `FRD.exe --secure-worker` 进入 Winlogon 桌面，采集锁屏与 UAC 画面，并处理安全桌面输入；不安装或分发独立辅助可执行文件，不增加外部端口。
- 服务安装或修复后，当前发送会话每秒重试附加安全桌面共享帧源，无需主控断开重连。

已编译主工程和生成的单文件 Demo。安装动作会改变 Windows 服务配置，因此本版本未在发布构建机自动触发 UAC 或真实安装；首次点击由被控端本机用户确认。
