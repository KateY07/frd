# 交互方案与回归

## 方案依据

RustDesk 将鼠标形状、位置作为独立消息，并在两端缓存形状，已知形状只需发送标识。Windows 形状数据包含热点和像素；RDP 指针协议也支持形状缓存及显隐更新。因此 FRD 采用独立鼠标通道，在预览区域设置本机原生指针，位置移动无需等视频帧。

- [RustDesk 鼠标服务与形状缓存](https://github.com/rustdesk/rustdesk/blob/master/src/server/input_service.rs)
- [RustDesk Windows 鼠标数据](https://github.com/rustdesk/rustdesk/blob/master/src/platform/windows.rs)
- [RDP 指针更新](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpbcgr/f68241f5-79bc-4c60-95d6-79ff47e2a302)

Sunshine 的 Windows DXGI 路径获取独立指针形状，通过 GPU 将 alpha/XOR 鼠标纹理合成进捕获画面。这与单独传递形状是不同的选择，不能笼统地说所有竞品都采用同一种方案。FRD 当前优先远程桌面操作时的指针响应。

- [Sunshine Windows GPU 鼠标合成](https://github.com/LizardByte/Sunshine/blob/master/src/platform/windows/display_vram.cpp)

文件通过独立可靠连接接收到本机暂存目录，校验后发布 `CF_HDROP` 和复制效果。资源管理器处理用户选择的最终目的地、合并、替换与复制进度；FRD 不自行替代这些 Windows 交互。

- [Windows Shell 剪贴板数据格式](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard)

## 本机验证

- 双向文本包含 Unicode、多行和空文本；双向文件包含二进制内容、重复顶层文件名、嵌套目录和空目录，逐项校验 SHA-256。
- Windows 实际 `CF_UNICODETEXT` / `CF_HDROP` 读写双向验证；测试前备份原有格式，完成后恢复。
- 验证回环抑制、路径拒绝、传输中断不发布半成品，以及未完成暂存目录清理。
- 八种标准鼠标形状的像素、AND/XOR 掩码和热点通过重建回读验证。
- 实际捕获与解码输出为 2880×1800、2160×1350、1440×900；三种主控窗口大小下，真实目标收到 9 次位置正确的点击、9 组键盘扫描码和 9 次滚轮事件，Esc 退出并释放按键。
- localhost 的主控与目标共享桌面；测试在键盘阶段明确激活自有目标窗口，避免将同桌面焦点竞争误当作双机行为。双机测试不使用这个辅助步骤。

本机测试原始报告位于 `results/interaction/`（不提交桌面或剪贴板数据）。

## 双机验证状态（2026-09-18）

- RTX 5070 Ti 被控端到本机主控的真实桌面 Demo 已显示；用户反馈“效果很好”，记录为本次可视体验确认。
- 双机自动化已验证实际解码尺寸为 2560×1440、1920×1080、1280×720，以及无效比例保留原会话。
- 用户人工确认键鼠操作正常，按要求暂停自动键鼠测试。早先自动测试未确保对端接收窗口可见，不能作为成功证据；保留夹具可见性与坐标归属检查供以后显式运行。
- 两台机器各自的 Windows 剪贴板读写短测通过；跨机 A→B、B→A 的 Unicode 多行文本、二进制文件、重复文件名、嵌套目录及空目录均通过。校验内容 SHA-256，并确认接收端发布的是本机暂存路径。
- 两个方向均通过 Windows Shell 复制、同名文件替换、目录合并、保留目标额外文件及复制后重新读取验证。测试仅对自造数据自动确认；没有自动操作资源管理器的交互提示框，也没有以双击执行文件来代替内容验证。
- 测试先关闭同步再恢复两端原剪贴板，夹具均确认恢复后退出。双机实际 GPU 呈现与干净关闭通过，测试报告位于 `results/interaction/lan-20260918-watermark/`。
- UI 码率单位统一为 Mbps，0.5、5、10、20、5 Mbps 往返调整均收到发送端确认；软件编码器另以实际码量验证 0.5–20 Mbps 上限及 VBV 突发预算。默认滑条/数值输入范围 0.1–100 Mbps，上限可由 JSON 配置。
- 诊断信息与操作控件分离为半透明水印。验证原生命中返回穿透、禁止激活、与预览同 UI 线程，以及三种窗口尺寸下位于画面内；全过程发送键鼠事件数为 0。控制栏仍可操作、折叠。
- 主程序和同步生成的单文件 Avalonia 示例编译均为零警告、零错误。测试完成后已重开真实双机 Demo。
