# FRD v2.pre12

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 网络延迟始终可见：展开时显示在状态点旁，折叠后悬浮球变为带延迟读数的状态胶囊（连接前仍是普通悬浮球）。读数为诊断包测得的平均传输延迟，悬停显示端到端延迟与丢包率。
- 主控端连接成功后默认开启诊断包（开销很小），以便延迟可读；可在“更多”中关闭，关闭后跨机延迟不可测。
- “诊断信息”按钮恢复显示在“更多”中（诊断水印默认关闭，需要时手动开启）；“诊断包”按钮同样可见。
- 协议、端口、输入通道与安全桌面辅助服务不变，主被控端无需同时升级。

已编译主工程并通过控制浮层回归。折叠胶囊的窗口尺寸经实测，其画面没有截图确认；回归在编译后立即运行时曾两次偶发失败（最小化恢复步骤），空闲重跑 4 次均通过。
