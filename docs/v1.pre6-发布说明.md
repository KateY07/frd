# FRD v1.pre6

本版在已发布 v1.pre5 完成真实双机回归后发布。产品功能代码及编码配置与 pre5 相同，更新版本标识、README 和验收记录；保留旧版本标签。

## 双机验证通过

- RTX 5070 Ti 被控端真实桌面捕获，经 FFmpeg、UDP 到本机主控解码；H.264、AV1、HEVC 硬件编码切换、码率切换、鉴权、重连和独立诊断检查通过。
- 可视窗口中验证码率滑条 0.5 / 5 / 10 / 20 / 5 Mbps，并确认被控端实际接收相同设置。
- 传输比例 1× / 0.75× / 0.5× 对应真实解码尺寸 2560×1440 / 1920×1080 / 1280×720；窗口缩放和诊断水印穿透检查通过。
- 双向多行中文与表情文本、同名文件、嵌套目录及空目录完成同步和 SHA-256 校验。接收端公布本地暂存路径，Windows Shell 复制、替换、目录合并及文件重新读取验证通过。
- 真实 GPU 呈现回归接收 377 帧，GPU 确认 341 帧，无错误；测试结束恢复双方原剪贴板，并关闭测试窗口。

自动键鼠注入继续暂停，不将本次回归表述为键鼠自动化验收。详细证据与限制见 [检查和回归记录](v1.pre6-静态检查.md)。CLI 使用方式见 [使用](使用.md)。

发布包含 README、自包含 Windows x64 程序、可编辑 JSON 和 FFmpeg 依赖。只推送版本标签及引用的源码提交；ZIP 与 SHA-256 保留本机，不上传 GitHub Releases。
