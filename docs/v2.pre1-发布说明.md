# FRD v2.pre1

Windows x64，依赖 .NET 10 x64 Runtime，不自包含、不启用 Native AOT。

本版修复 v1.pre13 静态审查确认的五类问题：

- 超长 UDP 报文与瞬态 socket 错误不再终止被控端公共接收循环；不可恢复错误即时通知会话并结束失效连接。
- 输入执行与 UDP 收包分离，安全桌面辅助进程 ACK 等待不会阻塞反馈及后续输入接收。队列最多 128 个事件，只合并连续移动；过载时清除积压并先释放全部按键/按钮。禁用和断开不会遗留队列中的输入。
- 同会话恢复测试增加新解码帧、被控端输入执行、诊断和反馈的强制断言，修正此前仅检查连接或转发包的不足。
- 诊断回调异常只停用故障回调并记录错误，不再使整个视频会话失败。
- 五次 UDP 注册超时后明确报告固定 UDP 转发规则错误，用户取消仍保留取消语义。

主被控仍只使用一组 TCP/UDP `--port`；TCP 可并发独立连接。UDP 最大 1172 字节，输入不增加跨机 ACK 或重发。安全桌面辅助进程的 localhost 通信属于被控机内部，不需要外部端口映射。

详细验证范围与边界见 [静态检查与回归](v2.pre1-静态检查.md)。安全桌面辅助进程仍不随便携包安装；本轮没有实测对机安全桌面或真实 ArdUi 公网链路。
