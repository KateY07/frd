# 输入生命周期修复（v2.pre2）

基于 v2.pre1，2026-09-22，随 v2.pre2 发布，保留既有版本标签和发布包。

## 修复

- 输入执行异常仅关闭输入通道，尝试释放按键；不取消视频与 UDP 反馈。
- 输入及剪贴板权限通道按桌面会话和通道实例确认所有权，旧任务退出不能清除新通道。
- 每次输入连接生成独立随机令牌，拒绝旧连接迟到的高序号包；重复启用不清空待执行事件。
- 远程 TCP 只处理输入启停，拒绝键鼠事件；事件仍通过固定 UDP `--port` 发送。
- 本地排队超过 250 ms 时丢弃积压并释放按键，保留输入通道接受新事件。此值从被控端收到事件开始计时，不是网络超时或端到端时延保证，也不能中断已经进入的本机系统调用。

## 兼容性

输入 TCP 握手增加 `InputProtocol: 2`，回复携带独立 `InputSession`。主控与被控必须一起更新；旧输入握手明确拒绝，不静默回退。UDP 输入包仍为 56 字节，视频数据报上限仍为 1172 字节，外部仍只需同端口一组 TCP/UDP 映射。

## 实测

- `PathSwitchResilience --input-lifecycle-only`：旧令牌拒绝、输入异常隔离、重复启用、过期积压后新输入恢复、TCP 事件拒绝、旧权限通道清理，全部通过。输入使用 mock，不操作真实键鼠。
- `PathSwitchResilience --udp-resilience-only`：异常大包、输入阻塞隔离、诊断失败降级、队列上限、注册超时提示等通过。
- `MouseFollowDual --udp-loopback`：UDP 移动、点击、滚轮、按键、释放及鉴权/旧包拒绝通过。
- `InputPipeline`：36 项通过，报告 `results/input-fix-pipeline.json`。
- `Remote --auth-only`：真实进程认证、新旧输入握手、独立令牌通过，报告 `results/input-fix-auth.json`。
- `PathSwitchResilience --same-session-only`：100/500/1000/3000/5000/10000 ms 原连接停顿、UDP 丢包乱序及辅助通道断开恢复通过，日志 `results/input-fix-same-session.log`。本轮 DXGI 返回 Access Denied，回退 GDI；验证的是新解码帧和输入执行计数恢复，不能据此宣称真实动态桌面、GPU 呈现或双机体验已验收。
- 主工程及同步后的单文件 Avalonia Demo 编译通过。

初版新增策略曾在一次本地输入调用超过 250 ms 后关闭输入通道，导致恢复回归失败。已改为仅丢弃过期积压并保留通道，以上为修正后的结果。
