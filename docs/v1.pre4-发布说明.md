# FRD v1.pre4

Windows x64 / C# / Avalonia / FFmpeg 远程桌面原型。本版把已确认的界面交互接入真实桌面 Demo。本机短测通过，UI 已获人工确认；按本次发布安排，先发布 v1.pre4，再进行完整回归。若回归发现问题，修复后递增 pre 版本重新发布，不覆盖本版标签。

## 本版变化

- 主控、本机演示、被控及帮助窗口统一采用 Avalonia Simple 主题，控制栏保持紧凑布局。
- 码率仅通过滑条调整，当前数值在标签中以 Mbps 显示；滑条上限继续读取 JSON 的 `maximumBitrateMbps`。
- 主控与本机演示支持全屏按钮和 Ctrl+Alt+F11；Ctrl+Alt 退出键鼠转发。启用转发时，单独按 Esc 或 F11 仍传给远端。
- 控制栏展开时可拖动空白区域，交互控件仍正常操作；收起为 50 像素半透明悬浮球后仍可拖动，单击恢复控制栏。两种状态均限制在视口内，窗口缩放时保留当前位置并按可见范围调整。
- 诊断水印可独立隐藏，保持鼠标穿透且不获取焦点。显隐仅影响界面，不改变诊断采集或独立 UDP 诊断包的开关。
- 主工程与生成单文件 Demo 项目的版本均为 `1.0.0-pre4`，显示版本为 `v1.pre4`。

## 保留的接口与边界

控制台 EXE 的 CLI 持续阻塞至清理退出；被控端仍需每次明确传入 `--host --listen ADDRESS --port PORT --token TOKEN`，无默认口令或默认监听地址。IPv4/IPv6、编码预设、码率、传输比例、键鼠、鼠标形状及双向剪贴板功能保持原有接口。

自动键鼠回归继续暂停。当前仍为单主控、可信局域网原型，通信未加密，不提供 NAT 穿透；跨机延迟包含时钟估算误差，GPU 完成不代表屏幕扫描完成。历史验证保留在 pre3 记录中，不能代替 pre4 验收。便携包含 README，保留本机；Git 发布源码和版本标签，不上传 GitHub Releases。使用方法见 [使用.md](使用.md)，本版验证状态见 [静态检查](v1.pre4-静态检查.md)。
