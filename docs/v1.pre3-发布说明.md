# FRD v1.pre3

Windows x64 / C# / Avalonia / FFmpeg 远程桌面原型。源码与版本标签推送到 Git，便携安装包留在本机，不创建 GitHub Release 附件。

## 本版变化

- 以单一 EXE 的 CLI 作为二次开发进程接口，README 提供启动参数、配置、日志、退出与 C# 集成示例；控制台入口保持阻塞直到程序退出，新增纯文本帮助和版本查询，未知入口明确报错。
- 被控端每次必须显式传入非空 `--token`，不生成、不保存、不恢复口令；主会话与附属通道逐一认证。监听端口占用时非零退出。
- 被控端 `--listen`、`--port` 同样每次必填；不默认绑定 `0.0.0.0`。`localhost` 仅绑定两种回环；`::` 使用单个 IPv6 双栈 Socket，同时接受 IPv4/IPv6。视频、诊断及附属连接均支持两种协议。
- 默认原始分辨率传输，可切换 1×、0.75×、0.5×；主控窗口保持等比例显示。
- 码率使用 Mbps 滑条和数值输入，默认 0.1–100 Mbps，可通过 JSON 配置上限；不施加额外链路限速。
- 独立鼠标形状通道，保留热点和显隐信息；键鼠操作已由用户人工确认。
- 可选双向剪贴板同步：文本、文件、目录；文件完整暂存及校验后交给 Windows 文件剪贴板。
- 诊断改为半透明水印，鼠标穿透、不获取焦点；操作控件独立可折叠。
- 修复稀疏丢帧造成诊断历史无法及时淘汰的问题，修复缩放尺寸元数据及测试清理结果记录。
- 发布使用全新暂存目录，阻止测试程序混入；提供 ZIP 和 SHA-256。过时实验及构建已归档，保留可追溯清单。

## 验证与边界

已有本机与 RTX 5070 Ti 双机回归覆盖码率控制、三种传输比例、真实 GPU 呈现、双向剪贴板内容和 Windows Shell 复制/替换/合并。发布验证结果见静态检查记录；自动键鼠测试按用户要求保持暂停。

当前支持 IPv4/IPv6 双栈，仍为单主控、可信局域网原型；通信未加密，不包含 NAT 穿透。静止内容不保证零码率或无损，AV2 在所带 FFmpeg 构建中不可用。GPU 完成时间不代表物理屏幕扫描完成；跨机总延迟包含时钟估算误差。代码仍有逐帧 BGRA 大数组分配，本次不宣称零拷贝或全流程低于 1 ms。

解压整个 ZIP 后运行 `FRD.exe`；双机命令和预设配置见同目录 `使用.md`。FFmpeg 许可证见 `ffmpeg/LICENSE.txt` 和 `THIRD-PARTY-NOTICES.md`。
