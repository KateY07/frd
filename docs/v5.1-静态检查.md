# FRD v5.1 静态检查

检查范围：FFmpeg 查找（`src/Codec/FfmpegLocator.cs`、`FfmpegRuntime.Configure`）、FFmpeg 扩展安装器（`tools/FfmpegSetup`）、相关文案与翻译。

- 版本：两个项目为 `5.1.0` / `v5.1`，与标签一致；协议、端口、预设不变。
- 查找顺序：`FRD_FFMPEG_DIR` → `FRD.exe` 旁的 `ffmpeg\`（`libraryDirectory`）→ `%LOCALAPPDATA%\FRD\ffmpeg\<版本>\`（按 `System.Version` 取最新，不可解析的名字排后）。一个目录要同时有 `avcodec-62`、`avutil-60`、`swscale-9`、`swresample-6` 才算完整；读用户目录失败按“未安装”处理。
- 安装器：写入目标固定在当前用户的 `%LOCALAPPDATA%` 下（`FFMPEG_TARGET` 仅用于脚本和测试），不再在其他程序（例如另一个应用自带的 FRD 目录）里写文件——此前的版本在无人值守模式下可能选中别处的 FRD 副本，这一类问题已因不再搜索 FRD 而消失；窗口模式只在目标已存在或首次安装时询问一次。
- 文案：缺失扩展的提示改为“运行 FFmpeg 扩展安装器，或把其中的 ffmpeg 文件夹放到 FRD.exe 旁”，中英文翻译表同步。
- 兼容：v5.0 及更早的 FRD 不识别用户目录的安装，发布说明和扩展页已写明，zip 方式不变。
- 未覆盖：安装器窗口里的点击交互；多个用户共享同一台机器时每个用户各装一份（设计如此，不写系统目录）。
