# v2.pre2 静态检查与验证

本版修复输入故障扩大为视频故障、旧权限通道清理越界、输入令牌重用、重复启用清队列及 TCP 输入事件绕过 UDP 分流等问题。

验证记录和边界见 [输入生命周期修复](输入生命周期修复.md)。针对性输入生命周期、公共 UDP 异常恢复、UDP 键鼠回环、认证握手均通过；原输入流水线 36 项回归通过。同会话 100/500/1000/3000/5000/10000 ms 停顿、丢包乱序、辅助输入连接关闭与重连通过。

主工程和生成的单文件 Demo 编译通过。DXGI 在本轮本机恢复测试中返回 Access Denied，回退 GDI，因此不宣称真实动态画面、GPU 呈现或公网体验全部验收。alipc 双机预览能连接、创建窗口并启动解码；人工完整确认尚未记录。

原端口、来源校验、鉴权及 UDP 数据报大小保持不变。输入协议升级需同步更新双方。安全桌面辅助服务仍不随便携包安装。
