# FRD v2.pre15 静态检查

检查范围：`FRD.csproj`（FFmpeg 文件清单、目标框架）、发布脚本对文件清单的假设、版本元数据和发布说明。

- `FRD.csproj` 的信息版本为 `v2.pre15`，与 Git 标签及输出目录一致。
- FFmpeg：代码中的 `ffmpeg.*` 调用只涉及 libavcodec、libavutil、libswscale；对 avformat、avfilter、avdevice 无调用。swresample 为 avcodec 的依赖，予以保留。`Publish.ps1` 的必需文件检查（`avcodec-62.dll`、`avutil-60.dll`、`LICENSE.txt`）仍满足。
- 目标框架：源码中没有对 `Windows.*` 运行时类型的引用，去掉 SDK 版本号后可正常编译，输出目录不再含 `Microsoft.Windows.SDK.NET.dll` 与 `WinRT.Runtime.dll`。
- 打包：`Publish.ps1` 会把 `*.pdb` 移出发布目录；手工 `dotnet publish` 会带上 Skia/HarfBuzz 的约 100 MiB 符号文件，不属于发布包。
- 验证：控制浮层回归、CPU 预设回归、远程会话与 `--version` 通过；`--codec-regression` 失败项与改动前构建一致（17 项 `keyFrame`）。
- 未覆盖：`demo/FrdDemo.csproj` 仍使用旧的全量 FFmpeg 通配与旧目标框架，本版未改动；`Get-FFmpeg.ps1` 仍下载完整运行时到 `third_party`，只是不再全部打包。
