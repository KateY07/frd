# FRD v2.pre2

Windows x64，依赖 .NET 10 x64 Runtime，不自包含、不启用 Native AOT。

- 输入执行异常仅停用输入并释放按键，不再终止视频和反馈。
- 修复旧输入/剪贴板通道清理影响新通道权限、旧输入连接迟到包干扰新连接、重复启用清空输入队列的问题。
- 本地输入积压超过 250 ms 时丢弃待执行事件并释放按键，保持通道接受新输入。该阈值不是网络停顿超时。
- 远程 TCP 仅控制输入生命周期，键鼠事件统一走固定 UDP `--port`。

**主控与被控必须同时更新。** 输入握手升级为协议 2，每次输入连接使用独立随机令牌；旧版本输入握手明确拒绝。端口约定不变，UDP 输入包仍为 56 字节，视频数据报上限仍为 1172 字节。

本机针对性回归及 100 ms～10 s 同会话停顿恢复已通过。双机预览已启动，未将人工未反馈的行为记为验收通过。详见 [静态检查与验证](v2.pre2-静态检查.md)。
