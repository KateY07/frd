# FRD v2.pre14 静态检查

检查范围：被控端捕获的安全桌面过渡处理（`FfmpegDesktopSource.cs`）、版本元数据和发布说明。

- `FRD.csproj` 的信息版本为 `v2.pre14`，与 Git 标签及输出目录一致。
- 新增 `InputDesktop.IsSecure()`（`OpenInputDesktop` 失败或桌面名不是 Default 即为安全桌面）与 `SecureDesktopActiveException`；无辅助服务时，安全桌面期间不再触碰普通捕获后端（避免捕获路径被降级），返回空帧并等待。竞态下已进入捕获的失败，再检查一次输入桌面，仍判为过渡。
- `SecureUsable()` 每 2 秒查询一次辅助服务状态，仅在服务运行时信任共享帧文件的“活动”标记；状态查询失败按“不可用”处理，退回普通捕获。
- 不改动传输、编码、输入协议、端口、界面或服务权限模型。
- 验证：SY0812A 实机复现（修复前被控端进程在 UAC 后退出，会话日志含 `GdiDesktopCapture.Fail` 与 `host-process exit-code-1`）与修复后验证；控制浮层回归通过。未覆盖：锁屏、Ctrl+Alt+Del 的实机验证；辅助服务被强杀后的恢复仅通过本机陈旧标记的现象与代码审查确认。
