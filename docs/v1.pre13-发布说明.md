# FRD v1.pre13

Windows x64、依赖 .NET 10 x64 Runtime 的便携预发行版。

本版修复 v1.pre12 的端口协议回归。被控端只在 `--port` 指定的数值上监听 TCP 与 UDP；主控的全部 TCP 连接和 UDP 数据报只以其 `--port` 为目标。控制握手不再交换视频、诊断或发送端口。视频、反馈、诊断和全部键鼠输入由一个 UDP socket 按包类型复用。

主控使用带会话随机值的 UDP 注册包建立回程映射，被控端只向经过鉴权关联的实际 UDP 来源端点回包。UDP 映射缺失时主控会重试并明确报告固定端口不可达，不再表现为静默无画面或无输入。

ArdUi/ardJ 已确认同一端口映射允许多个并发、独立的 TCP 连接。FRD 当前单会话最多使用 4 条，低于其入口 8 条上限；FRD 最大 UDP 数据报为 1172 字节，低于其 1482 字节上限。

便携包不自包含 .NET，也不启用 Native AOT。主控与被控机器需预先安装 .NET 10 x64 Runtime。安全桌面辅助进程仍未包含于便携包；码率仍由用户手动控制。

验证见 [v1.pre13 静态检查](v1.pre13-静态检查.md)。
