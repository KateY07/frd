# FRD v1.pre12

Windows x64、依赖 .NET 10 x64 Runtime 的便携预发行版。

被控端在同一个 `--port` 同时绑定 TCP 与 UDP。主控开启键鼠转发后，鼠标移动、按钮、滚轮和键盘均向该固定 UDP 端口发送单个数据报。数据报带有当前会话随机令牌、严格递增序号和事件类型；无 ACK、无重发，错误会话和旧包直接丢弃。

TCP 继续承担认证、会话控制、剪贴板、鼠标形状与输入生命周期。经 FRP 等转发器使用时，同一外部端口各配置一条 TCP 和 UDP 映射即可。关闭转发或输入 TCP 断开时，被控端执行全量按键/按钮释放。

便携包不自包含 .NET，也不启用 Native AOT。主控与被控机器需预先安装 .NET 10 x64 Runtime。安全桌面辅助进程仍未包含于便携包；码率仍由用户手动控制。

验证见 [v1.pre12 静态检查](v1.pre12-静态检查.md)。
