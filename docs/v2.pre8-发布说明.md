# FRD v2.pre8

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 被控端窗口重做为与主控端一致的深色毛玻璃面板：状态点与“被 xxx 控制”、键鼠/剪贴板权限开关、断开、更多、`»` 收起。可拖动；空闲 10 秒自动收起；被控时收起为“被 xxx 控制”状态胶囊，未被控时收起为悬浮球；主控连入时自动展开。“更多”显示监听地址、会话时长与安全桌面辅助服务状态。
- 被控端窗口不抢键盘焦点，已排除出屏幕捕获，远程鼠标落在其上会被拒绝，因此主控端既看不到也无法操作它。
- 悬浮球悬停时保持毛玻璃底色；主控面板与被控端窗口收紧留白，提高玻璃底色不透明度以改善小字可读性。
- 协议、端口、输入通道与安全桌面辅助服务不变，主被控端无需同时升级。

已编译主工程并通过控制浮层回归。毛玻璃依赖 Windows 10/11 系统亚克力，不支持时退化为半透明。
