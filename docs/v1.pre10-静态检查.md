# FRD v1.pre10 静态检查与发布验证

本版程序功能与 v1.pre9 相同，功能回归依据 [v1.pre9 静态检查](v1.pre9-静态检查.md)。新增检查集中在自动发布链路：

- 工作流只由 `v*` 标签自动触发，也可手动运行构建；发布权限限定为 `contents: write`。
- runner 使用 .NET 10 SDK 和仓库内固定来源、固定 SHA-256 的 FFmpeg 包，随后调用与本机相同的 `Publish.ps1`。
- 发布前验证 Git 标签与 `FRD.csproj` 的 `InformationalVersion` 完全一致，并重新核对 ZIP SHA-256。
- Actions artifact 和 GitHub Pre-release 均包含 Windows x64 ZIP 与 `SHA256SUMS.txt`；发行说明来自本文件同目录下的版本化文档。
- 已存在的标签不移动；自动发布能力通过新标签 `v1.pre10` 启用。

GitHub runner 无真实桌面和目标 GPU，因此工作流只执行确定性的构建、打包和产物校验，不宣称代替真实屏幕、硬件编码器或双机交互回归。
