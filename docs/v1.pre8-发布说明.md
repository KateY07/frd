# FRD v1.pre8

本版修复 pre7 遗留的 Demo 输入限制，并改为依赖 .NET 10 x64 运行时的发布方式。

本版移除为本机 Demo 添加的生产输入限制与专用测试目标，恢复真实键鼠转发：

- 所有 `--connect` 会话均连接实际被控端的输入服务；不再根据 peer 是否为回环地址改用专用测试窗口。经 localhost 端口隧道连接异机，也不再因此被限制为滚轮和键盘。
- 无参本机演示使用原有 `Win32InputInjector`，允许鼠标移动、按键、滚轮及键盘事件；保留 FRD 窗口防回注处理。本机主控与被控共享系统指针，不能据此模拟双机各自独立的鼠标。
- 保留 pre7 的有界输入流水线、独立 ACK 接收、关闭与故障释放处理。

编码预设和码率继续由用户手动选择，不实现自动降码率，不引入新的 UI 或公网拥塞控制。

## 发布形态

主程序与单文件 Demo 保持 .NET 10，默认不自包含、不启用 Native AOT。两端预先安装 .NET 10 x64 Runtime 后直接运行 `FRD.exe`；FFmpeg 与 Avalonia 原生依赖继续随包提供。原生 PDB 调试符号单独保存在本机构建目录，不进入 ZIP。相同运行时下，打包方式不增加编解码或输入转发处理步骤；本轮未执行专门的性能 A/B 测试。

## 本轮验证

- 原输入协议、坐标映射和隐藏窗口消息回归 30 项通过。
- 流水可靠性回归 36 项通过，含新增混合鼠标/拖动/键盘序列及禁用后拒绝检查；仅使用真实 localhost TCP 和模拟注入器。
- 主项目与生成的单文件 Demo Release 构建均为 0 警告、0 错误。

本版检查范围见 [静态检查与验证记录](v1.pre8-静态检查.md)，CLI 用法见 [使用](使用.md)。没有实际全局键鼠注入或新增双机/RDP 对测。正式包的 SHA-256 随包提供，Git 只推送版本标签，ZIP 保留本机。
