# FRD v2.pre3

Windows x64，依赖 .NET 10 x64 Runtime，不自包含，不启用 Native AOT。

- 默认使用 `h264`（限码率质量优先），编码上限 2.5 Mbps。默认关闭自动选编码器，避免启动时替换为速度优先预设；仍可通过 JSON 主动启用自动探测或手动切换。
- 将 UDP 视频反馈统计移出公共收包线程，单槽保留最新累计反馈；输入与反馈各自执行，避免统计锁阻塞输入。UDP 收包使用独立线程。
- 增加内部输入阶段测时及呈现延后计数，加入真实鼠标到位至返回画面 GPU 完成的双机测试。

同端口 TCP/UDP 约定、1172 字节最大 UDP 数据报以及输入协议 2 不变；从 v2.pre1 或更早版本升级时主被控需一起更新。

定向统计锁阻塞回归已通过。正常局域网闭环短测仍有波动，尚未证明整体鼠标体验显著改善；不将发包完成、ACK 或内部模拟注入时间称为完整鼠标延迟。受限公网转发链路尚未验收。

遵照用户要求先发布，完整可观测性静态审计将在发布后继续。详见 [验证范围](v2.pre3-静态检查.md) 和 [输入延迟实测](单端口输入延迟回归.md)。
