# FRD v4.pre2 静态检查

检查范围：辅助服务安装（`tools/FrdWinTools/SecureService.cs`）、本地键鼠监视（`src/Channels/LocalInputMonitor.cs`）、标注通道与覆盖层（`src/Channels/Annotation.cs`、`src/Ui/UiAnnotationOverlay.cs`、`src/Ui/AnnotationBoard.cs`）、传输进度（`src/Channels/Clipboard.cs`）、远程光标叠加（`src/Ui/RemoteCursorOverlay.cs`）、帧率校验、面板布局。

- 版本：两个项目的信息版本均为 `v4.pre2`；协议握手版本不变（`RemoteAuth.Version = 3`），新增消息均为附加字段或新通道，旧端忽略。
- P/Invoke：`CreateService` 的 `lpdwTagId` 是 `LPDWORD`，必须按指针宽度（`nint`）声明；32 位声明在 NativeAOT 下会把寄存器高位的垃圾当作指针。已改，并已在目标机实机安装通过。主程序其余 `DllImport` 中同类的“32 位参数承载指针”问题未做全量审计，建议下个版本做一次。
- 键鼠监视：低级钩子只读 `flags` 的“注入”位和时间戳，不读取虚拟键码、字符或坐标；钩子回调只写一个时间戳。钩子看不到安全桌面（UAC/锁屏）。
- 标注通道：独立 TCP 连接，同样经挑战-应答认证并绑定会话和控制端地址；消息有长度、操作、坐标范围、文本长度校验，被控端每秒最多处理 120 条 add（其余丢弃，begin/end/undo/clear/text 不丢）；覆盖层最多 1000 个图形、每图形 2 万点，主线程每 33 ms 最多处理 300 条。发送端为 BelowNormal 优先级的专用线程，队列满则丢最旧，不会阻塞主控 UI。
- 覆盖层：`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，排除出屏幕捕获；实测点击能穿透到其他进程的窗口。
- 传输进度：回调节流到每秒约 10 次，结束或出错时清空。
- 帧率：允许值改为 10/20/25/30（`AppConfiguration`、`DemoSession`、UI、回归同步）。
- 布局：`UiLayoutRegression` 对控制端 32 种、被控端 16 种尺寸/状态检查控件重叠与越界，0 问题。
- 编译：主程序、辅助服务、Glasspane 均 0 错误；Glasspane 示例有 2 条可空性警告。
- 未覆盖：键鼠签名端到端；标注在多显示器或非主显示器捕获时的行为（覆盖层只覆盖主显示器，与捕获一致）；文字标注的输入法组合输入。
