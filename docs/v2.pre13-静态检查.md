# FRD v2.pre13 静态检查

检查范围：安全桌面辅助服务安装（`FfmpegSecureService.cs`）、密钥读取（`FfmpegSecureDesktop.cs`、`FfmpegSecureInput.cs`）、崩溃日志（新增 `FfmpegCrashLog.cs`）、被控端异常处理、版本元数据和发布说明。

- `FRD.csproj` 的信息版本为 `v2.pre13`，与 Git 标签及输出目录一致。
- 提权安装接受可选参数 `--install-secure-helper <SID>`，SID 经 `^S-1-\d+(-\d+)+$` 校验；无参数时沿用当前身份。授权范围不变：SYSTEM 完全控制，指定用户对密钥只读、对共享帧文件完全控制，且断开继承。该 SID 来自未提权的父进程，攻击面仅限于同一账户已通过 UAC 同意的操作。
- `SecureDesktopUdp.TryReadKey` 只吞掉 `UnauthorizedAccessException`、`IOException`、`InvalidDataException`，并记录日志；服务端 worker 仍使用抛出异常的 `ReadKey`。
- 被控端 `Dispatcher.UIThread.UnhandledException` 标记为已处理并写崩溃日志，可能使界面处于不一致状态，换来的是进程不消失；原生崩溃不在此覆盖范围。
- 验证：开发机上安装流程可通过，控制浮层回归通过；用独占锁模拟密钥不可读时，新旧版本被控端均未退出（该情形在开发机上本就不崩）。**未能复现 SY0812A 的闪退，本版加固是否解决该问题未验证。**
