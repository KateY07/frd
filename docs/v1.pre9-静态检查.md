# FRD v1.pre9 静态检查与回归

本版发布前检查范围为当前生产源码、生成的单 C# 文件 Demo、固定端点网络路径回归、输入流水回归和便携包内容。编译通过不代表所有硬件编码器已在目标设备验证。

## 网络情形与故障定位

测试转发器保持 FRD 可见的本机 TCP 端点、UDP 端口及会话身份不变；暂停时不发 FIN/RST，TCP 字节等候原连接继续交付，UDP 包可丢失。修复前，本机复现 10 秒暂停导致键鼠确认 5 秒超时，客户端主动关闭输入 TCP；修复后 100 ms、500 ms、1 s、3 s、5 s、10 s 的控制状态和安全输入命令均在原连接恢复，连接数不变。静止桌面可不产生新视频帧，因此会话级测试不把每次暂停后必有新帧作为条件。

另测视频 UDP 丢包/乱序、仅视频 UDP 暂停、仅诊断 UDP 暂停、仅反馈 UDP 暂停和仅键鼠 TCP 暂停。明确关闭键鼠 TCP 后可新建附属输入通道，控制/视频仍保持原会话；明确关闭控制 TCP 则报告错误，不伪装为路径恢复。真实 Avalonia 主控窗口经过 10 秒同端点停顿后仍存活并继续 GPU 呈现，测试关闭前累计确认 21 帧；键鼠附属通道单独关闭时视频继续，控制 TCP 明确关闭后窗口保持并提供手动建立新会话入口。

运行方式见源码中的 `tests/PathSwitchResilience/README.md`。现场原始故障日志和退出码此前缺失；新日志只包含 UTC 时间、进程号、事件顺序、异常类型/HRESULT 与堆栈，不写入口令、会话凭据或剪贴板内容。此本机模拟不能证明任意长断网可恢复，也不能替代真实转发器现场切换。

## 其他回归与发布边界

- 输入流水回归 36 项通过，包含 64 个在途请求的有界背压、超过 5 秒仍保持原 TCP 连接、恢复后顺序确认、取消/断开时释放按键。本机测试使用模拟注入器，不向用户桌面自动注入键鼠。
- 主项目、单文件 Demo 和固定端点回归工程须在发布前完成 Release 构建；发布包需核对版本、.NET 10 框架依赖、README/说明文档、FFmpeg 库、ZIP 成员与 SHA-256。实际结果以本次发布产物为准。
- 不纳入 `NativeVplProbe.obj`、嵌套的 libvpl 检出、测试 ZIP、辅助进程测试包或运行时错误日志。SYSTEM 安全桌面辅助进程未打包；因此便携版的锁屏/UAC 控制能力不以本轮开发机实验作保证。
- 码率继续由滑块手动控制；不实现自动拥塞降码率。没有本轮真实双机网络路径切换、不同 GPU 全覆盖或 RDP 对照结论。
