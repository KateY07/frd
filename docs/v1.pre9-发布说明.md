# FRD v1.pre9

Windows x64、依赖 .NET 10 x64 Runtime 的便携预发行版。完整目录包含 `FRD.exe`、可编辑的 `codec-config.json`、FFmpeg 原生库、README 与说明文档；不自包含、不启用 Native AOT。安装包保留本机，GitHub 只推送版本标签及其源码提交。

本版把开发阶段的原始分辨率捕获/编码改动纳入发行：提供 `libx264rgb`、低位宽彩色和灰度等预设，支持 10/20/30/60 FPS 与启动时限时编解码探测。编码预设及码率上限仍由用户手动选择；没有自动降码率或链路限速。不同预设的画质、码率和延迟需在实际设备上确认。

修复了本机转发端口保持不变、底层路径暂停时的一条确定故障路径：原键鼠通道等待确认超过 5 秒会主动关闭仍可恢复的 TCP 连接。现在等待期间保留原连接；视频 UDP 丢包与残帧按现有恢复机制处理。单独的键鼠通道断开只影响键鼠，主控窗口继续显示视频；控制 TCP 明确关闭时保留窗口、显示原因，并由用户手动建立新会话。生命周期日志写入 `%LOCALAPPDATA%\FRD\session-<PID>.log`，记录异常类型、通道关闭顺序及退出码，不写入口令或剪贴板内容。

本机固定端点转发器覆盖 100 ms 至 10 s 的同一会话停顿，以及 UDP 丢包/乱序和分通道中断；真实 Avalonia 窗口经 10 s 暂停后继续呈现。现场原始故障日志尚未取得，不能认定 5 秒键鼠确认超时是唯一根因；本轮也没有复现真实双机转发器的外部路径切换。源码中的 SYSTEM 安全桌面辅助进程仍属受信任测试部署，未纳入便携包，不承诺开箱即用的锁屏/UAC 无人值守控制。

详细验证与边界见 [静态检查](v1.pre9-静态检查.md)，CLI 使用见 [使用与配置](使用.md)。
