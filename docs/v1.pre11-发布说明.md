# FRD v1.pre11

Windows x64、依赖 .NET 10 x64 Runtime 的便携预发行版。程序功能与 v1.pre9 相同；本版继续完善 GitHub Actions 自动发布。

云端已经验证从标签源码恢复固定 FFmpeg 运行库、构建、打包、版本校验和 Actions artifact 上传。v1.pre11 将最终发布步骤改为直接调用 GitHub Release REST API，并把官方 checkout、setup-dotnet 和 upload-artifact 更新到使用 Node.js 24 的版本。成功后 GitHub Pre-release 同时提供 Windows x64 ZIP 与 `SHA256SUMS.txt`。

便携包不自包含 .NET，也不启用 Native AOT。主控与被控机器需预先安装 .NET 10 x64 Runtime。SYSTEM 安全桌面辅助进程仍未纳入便携包；码率仍由用户手动控制，没有自动拥塞降码率。

功能验证和边界见 [v1.pre9 静态检查](v1.pre9-静态检查.md)，自动发布验证见 [v1.pre11 静态检查](v1.pre11-静态检查.md)。
