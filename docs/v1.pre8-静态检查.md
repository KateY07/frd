# v1.pre8 静态检查与验证记录

本记录区分本轮源码/构建检查、无头输入回归与最终包检查，不沿用历史结果冒充本轮实测。

## 变更范围

生产 UI 恢复实际被控端输入路径，移除 `LocalDemoInputTarget` 的接入、仅滚轮/键盘白名单及相关状态提示。测试专用行为不得因连接 peer 为回环地址而进入发布路径；localhost 隧道仍按普通 `--connect` 会话处理。

无参演示回到原有 `Win32InputInjector`，保留 FRD 窗口防回注。该保护用于避免控制自身形成反馈，不应变成屏蔽所有鼠标事件的替代实现。独立实验代码不计入正式 Demo 能力。

pre7 的 64 请求在途上限、顺序写入、独立 ACK、5 秒 ACK 超时，以及取消关闭、断线和错误后的释放处理继续保留。本版不接入自动降码率或新的生产拥塞算法。

## 结论边界

pre7 的 18 个延迟场景及 7 个网络模型场景是历史证据，本轮未重复。网络模型中的视频拥塞问题没有因恢复鼠标事件而解决，输入 ACK 也不等于画面完成渲染。

本记录没有新增 LAN、RDP 对比或真实应用输入到视频呈现的延迟结果。本机演示共享系统鼠标，鼠标争用与双机独立指针是不同场景。四窗口拒绝名单属于无参数 Demo 的注入器实例，不能宣称跨进程 loopback 也共享该名单；注入标记防重复采集继续保留。
