# FRD v3.pre1 静态检查

检查范围：`FRD.csproj`（Native AOT、依赖）、`FfmpegJson.cs`/`FfmpegReportJson.cs`（AOT JSON）、`MfInterop.cs`、发布脚本与工作流。

- `FRD.csproj` 的信息版本为 `v3.pre1`；`PublishAot` 默认开启，`InvariantGlobalization`，并以 `TrimmerRootAssembly` 保留 FRD 自身类型。`Avalonia.*` 包引用已移除，旧界面源文件已删除。
- JSON：.NET 10 的源生成在 `init` 属性缺失字段时不执行属性初始化器，因此被反序列化的配置类型改为 `set`；协议与配置类型通过 `PlainJsonContext`/`ConfigJsonContext` 生成元数据；匿名报告对象由 `ReportJson` 手写序列化（AOT 下 System.Text.Json 无法为匿名类型建元数据）。
- COM：`ICodecAPI` 由 `ComImport` 改为 vtable 函数指针调用（AOT 安全，无 RCW）。
- 打包：`Publish.ps1` 产出基础包（单个原生 exe、`codec-config.json`、文档，必须不含 `ffmpeg\` 与任何托管 DLL）和 FFmpeg 扩展包（四个库 + LICENSE + 第三方声明），`SHA256SUMS.txt` 含两者；`release.yml` 一并上传。
- 未覆盖：`demo/FrdDemo.csproj` 与 `tests/` 下旧工程仍引用 Avalonia 与旧 API，本版未改动；`--presentation-regression` 随旧界面移除，由 `--demo-regression` 取代。
- `frd-wintools`：`tools/FrdWinTools` 独立工程，链接 `FfmpegSecureShared/Desktop/Input.cs` 与从 `FfmpegInput.cs` 拆出的 `FfmpegInputInjector.cs`；服务主体（`SecureService.cs`）只在该工程中编译，主程序仅含 `FfmpegSecureHelper.cs`（状态查询与 UAC 启动）。在 AOT 构建上验证了 `--version`、`--secure-service`（在服务管理器之外按预期返回 1063）和 `--secure-worker`（按预期在非 SYSTEM 下无法打开 Winlogon 桌面）；服务的完整安装/运行需要管理员授权，未在本机执行。
